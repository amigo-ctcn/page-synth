# Free Simple MIDI Library — 4-bar Reference Patterns

This package contains 78 original MIDI files generated for a small reference phrase library.

Common constraints:
- 4 bars
- 4/4
- 80–100 BPM
- Simple patterns
- Mostly one musical track
- Intended for phrase reference, data sonification, arrangement prototypes, and Cline/REAPER/Gibber experiments

License:
- Original generated MIDI.
- Free to use, modify, redistribute, and include in your own projects.

Suggested usage:
- Keep these files as source reference phrases.
- In code, extract rhythm density, note spacing, pitch contour, and phrase shape.
- For generated music, treat them as phrase templates rather than fixed songs.

# Privacy Policy

PageSynth analyzes visible text and page features of the current tab locally in the browser only when the user presses **Play**.

## Data Use Purpose

- The analysis is used only for real-time music generation.

## Data Handling

- PageSynth does **not** upload webpage content to any server.
- PageSynth does **not** store browsing history.
- PageSynth does **not** sell, rent, or share user data.
- PageSynth does **not** use analytics, tracking, or advertising SDKs.
- PageSynth has no account system.
- PageSynth has no external server data transmission.

## Runtime Behavior

- The content script analyzes the current page only when the user presses **Play** from the popup.
- If page content cannot be analyzed, PageSynth falls back to basic music generation using tab title and URL.
- Users can stop playback at any time by pressing **Stop** or by closing the source tab.
